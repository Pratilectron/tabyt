TabYT in three steps

See how much memory your YouTube tabs use, close them without losing your place, and get them back when you are ready.

1

Review your tabs

Click the TabYT icon in your toolbar. Every YouTube tab appears with its title, playback state, last activity and an estimated memory reading. The largest tabs are easiest to spot.

2

Close without losing your place

Use Save & close on a tab or Save & close all to tidy up. TabYT records the video title and current playback position before closing. A normal close also saves when the setting is on.

3

Resume anytime

Open Saved videos and press resume. TabYT opens the video and seeks back to the saved timestamp, reusing an existing tab when possible.

How the memory readings work

Stable browsers do not expose exact per-tab memory to extensions. TabYT estimates each tab's memory from the video resolution, whether the video is playing, buffered media, page DOM size and the JavaScript heap where available. The result is a relative guide to which tabs are heaviest, not a replacement for the browser Task Manager.

Chrome builds that expose the Processes API can optionally report measured renderer memory. Firefox uses estimates because it does not provide this data to extensions.

Auto-close rules

When enabled, TabYT checks once per minute. A tab is closed only if it is a background YouTube tab, has been inactive past your threshold, and does not match a protection: pinned, audible or playing. The current tab in a focused window is never auto-closed.

Clicking, typing, scrolling, switching to the tab or starting playback resets its inactivity timer. A tab whose window is minimized or unfocused can be closed once the threshold passes.

Memory limits and alerts

The limit applies to the combined estimated memory of all open YouTube tabs. When it is crossed, TabYT can show a browser notification and, if you choose, close the least recently used eligible tabs. Alerts respect the cooldown so they do not become noisy.

Privacy and permissions

TabYT has no servers, no analytics and no accounts. It requests access only to YouTube pages, plus local storage, alarms, notifications and scripting. It does not read other sites, cookies or browsing history. Incognito tabs are ignored and never saved. All settings and history live in your browser's local extension storage.

Removing the extension also removes its local storage. Export your data first if you want a backup.

Troubleshooting

  • If a tab shows a stale reading, click Refresh. TabYT re-injects its content script if the page was open before installation or after an update.
  • If auto-close does not run, check the threshold, protections and that the tab is actually in the background.
  • If a resume starts from the beginning, the video may not have had a saved position, or YouTube changed its player markup. Reload the video and try again.
  • If measured readings are unavailable, your browser does not expose per-tab memory; estimates are working as intended.

Install & update

Chrome: open chrome://extensions, enable Developer mode and load the unpacked dist/chrome folder. Firefox: open about:debugging, choose “Load Temporary Add-on” and select dist/firefox/manifest.json.

Store installs update automatically. If you loaded the extension unpacked, run npm run build and reload it to update. TabYT reconnects open YouTube tabs on the next refresh.
