Automatic cleanup

Auto-close is off. Turn it on in Settings to close idle YouTube tabs after a set time.

About the readings

Browsers do not expose exact per-tab memory to extensions. TabYT estimates from video quality, playback, buffered media and page complexity, and can use measured process memory where Chrome exposes it. Treat the numbers as a guide for which tabs are heaviest.
